Version **rétrocompatible** : mise à jour sans rien modifier ni migrer à la main.

### Nouveautés

- **Paquet GitHub** pour **amd64 et arm64** (`ghcr.io/imperial-corporation/imperial-codecenter`), analysé, signé, avec SBOM et provenance ; release créée automatiquement à chaque tag.
- **Léger** : profils `lite` / `minimal` / `auto`, recherche via un index de contenu PostgreSQL (plus de relecture des fichiers), redémarrage rapide, pauses et priorités d'indexation, cache, `compose.lite.yaml` — pour petits serveurs, vieux PC et disques durs.
- **Administration** : comptes, inscriptions, progression de l'index en direct, exclusions, ressources, métriques Prometheus (`/metrics`).
- **Sauvegarde / restauration** chiffrables et planifiables.
- **Jetons d'API par compte**, CLI `icc` (`icc.pyz` joint à la release), serveur MCP.
- **Interface FR / EN**, secrets `*_FILE`, Podman, tests e2e, CodeQL.

### Fichiers de cette release

- `*.whl` : moteur Rust pour Linux amd64 et arm64 (macOS et Windows : au mieux) ; `*.tar.gz` : sdist et sources ; `icc.pyz` : CLI autonome ; `sbom.spdx.json` ; `SHA256SUMS`.
