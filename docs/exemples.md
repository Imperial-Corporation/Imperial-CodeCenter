# Scripts d'exemple

35 scripts commentés dans `examples/codes/` (algorithmes, API, concurrence, configuration, fichiers et données, système, web), installés une seule fois par `install_examples.sh` (marqueur `.examples-installed` ; `--force` pour réinstaller sans écraser tes fichiers). Ils servent de jeu d'essai pour la recherche et l'IA.
